\begin{abstract}
Property-based testing (PBT) needs efficient generators for inputs satisfying a
given predicate.
Existing derivation techniques can fail or yield inefficient generators for some
predicates.
Agents offer a new way to construct efficient generators for predicates that
existing techniques struggle to handle.
However, constructing and verifying generators poses reliability and scalability
challenges for agents.
We propose verified agentic predicate reformulation.
The agent rewrites the predicate and proves equivalence, while QuickChick derives
a verified generator.
Combining these proofs guarantees soundness and completeness for the original
predicate.
We evaluate the approach using a toolchain built on SpecTec, a domain-specific
language for specifying programming languages.
The toolchain constructs verified generators for property preconditions and uses
them to test external language implementations.
\end{abstract}
