\section{Background: SpecTec}
\label{sec:background}

\subsection{Overview}
\label{sec:spectec-overview}

\draft{SpecTec was introduced to mechanize the WebAssembly specification~\cite{youn24spectec}.}
\draft{It describes language syntax with grammar declarations and semantics with definitions and relations.}
\draft{P4-SpecTec adapts the framework to the P4 specification, including its typing and execution relations~\cite{lee26p4spectec}.}

\subsection{Syntax and Notation}
\label{sec:spectec-syntax}

\draft{We illustrate the notation used by P4-SpecTec with a small arithmetic language~\cite{lee26p4spectec}.}
\draft{A \texttt{syn} declaration defines a syntactic category: alternatives separated by \texttt{|} give constructors and their fields.}
\draft{The primitive type \texttt{nat} denotes natural numbers; suffixes \texttt{*} and \texttt{?} denote sequences and optional values.}

\begingroup
\color{draftgray}
\small
\begin{verbatim}
syn expr = | Lit nat | Add expr expr
rel Eval: expr : nat hint(input %0)

rule Eval/lit: Lit nat : nat
rule Eval/add: Add expr_1 expr_2 : nat
  -- Eval: expr_1 : nat_1
  -- Eval: expr_2 : nat_2
  -- let nat = nat_1 + nat_2
\end{verbatim}
\endgroup

\draft{Here, \texttt{Lit} contains a number and \texttt{Add} contains two expressions.}
\draft{The \texttt{rel} declaration introduces \texttt{Eval}, relating an expression to a number; the colon is part of its declared notation.}
\draft{Each \texttt{rule} gives one case of the relation, with its conclusion first and premises introduced by \texttt{-{}-} below it.}
\draft{The literal rule has no premises.}
\draft{The addition rule evaluates both subexpressions and binds their sum to the result.}

\draft{In P4-SpecTec, \texttt{hint(input \%0)} marks the first argument as input and leaves the other argument as output.}
\draft{Premises are processed in order: relation premises compute outputs from known inputs, \texttt{let} binds values, and \texttt{if} checks side conditions.}
\draft{Input annotations and binding checks make this dataflow explicit~\cite{lee26p4spectec}.}
\draft{Auxiliary functions are declared with \texttt{dec}, defined with \texttt{def}, and called using the \texttt{\$} prefix.}

\draft{An execution direction for a relation does not by itself provide a generator for its satisfying inputs; the additional requirements for generation and conclusion checking belong to Section~\ref{sec:propose}.}
