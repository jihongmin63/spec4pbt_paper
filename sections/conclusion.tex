\section{Conclusion}
\label{sec:conclusion}

\draft{This draft introduces a tested SpecTec-to-Lean translation and proposes connecting agent-written property-based tests to the translated specification through Lean-checked obligations for the property, generator, and oracle.}
\draft{A restricted SpecTec-like property language is intended to support automatic derivation of the executable test components and their obligations.}
\draft{The P4 evaluation will determine how well that connection works in practice.}

\draft{More broadly, if observable behavior can be specified and automated property checkers can be defined by other means, a similar approach may be possible without relying on SpecTec.}
