\section{Related Work}
\label{sec:related}

\paragraph{Generator derivation.}
QuickChick derives generators for inductive relations in Rocq together with
correctness
proofs~\cite{paraskevopoulou15foundational,lampropoulos18generators,paraskevopoulou22computing}.
Later work merges relations~\cite{prinz23merging} and chooses premise orders
automatically~\cite{mittelman26testing}.
Palamedes synthesizes generators for Lean predicates~\cite{goldstein26palamedes}.

\paragraph{Agentic property-based testing.}
LLM agents write property-based tests~\cite{maaz25agentic,lee26propertytemplates}.

\paragraph{Testing language implementations.}
Mechanized specifications have been used to test implementations of
WebAssembly, P4, and Ethereum consensus
clients~\cite{youn25west,lee26fwp,jeong26spectrum}.
