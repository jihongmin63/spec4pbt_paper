\section{A SpecTec-Based Toolchain}
\label{sec:instantiation}

\subsection{Specification and Property Inputs}
\label{sec:specification-inputs}

The toolchain translates a SpecTec specification and a property written in
SpecTec-like notation into Rocq.
The generator targets the property's precondition.

\subsection{Predicate Reformulation and Generator Derivation}
\label{sec:generator-verification}

The agent writes each reformulated predicate in the same SpecTec-like notation.
The toolchain translates it into Rocq, where the agent proves it equivalent to
the previous predicate and QuickChick derives a generator from it.

\subsection{Testing Language Implementations}
\label{sec:implementation-testing}

The user supplies adapters that run an implementation and map its observed
outcomes to the results of specification relations.
The checker calls these adapters in place of the relations, so it evaluates the
property's conclusion against the implementation on each generated input.
